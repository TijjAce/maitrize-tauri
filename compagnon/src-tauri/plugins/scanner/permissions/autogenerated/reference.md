## Default Permission

Photographier les pages d'un manuel, ajustées une à une ; ouvrir et refermer la page de connexion à Nuage.

#### This default permission set includes the following:

- `allow-photographier`
- `allow-ouvrir-connexion`
- `allow-fermer-connexion`
